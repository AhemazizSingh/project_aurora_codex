# Purpose

This document defines the visual identity of FinanceOS.

Every screen should immediately communicate:

Premium

Trust

Calm

Modern

Intelligent

The application should feel like a product designed by Apple rather than a generic finance dashboard.

---

# Design Rules

Never clutter.

Never overload.

Always prioritize readability.

Every screen should be usable with one hand.

Every chart should answer a question.

Every animation should have a purpose.

If a feature makes the interface more complex without helping users understand their finances, remove it.

---

# Final Design Goal

When a user opens FinanceOS for the first time, they should think:

"This looks like an Apple app that costs ₹999 per year."

Not

"This looks like another free expense tracker."
