# Analytics Design Rules

- Every chart answers a question.
- Every chart has an insight below it.
- Every insight links to actions.
- Never show charts without interpretation.
- Avoid clutter by grouping related analytics.
- All charts support dark and light mode.
- Use animations to reveal trends, not distract.
